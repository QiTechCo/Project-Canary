# Project Canary — Dimple Ajmera for Charlotte Campaign

Official campaign website and volunteer access portal for Dimple Ajmera for Charlotte City Council (At-Large).

## Tech Stack
- **Frontend**: HTML5, CSS3 (Custom Design System with Unified 2-Font Typography), JavaScript, Bootstrap 5.3
- **Volunteer Portal**: Passwordless Authentication & Supabase PostgreSQL Backend
- **Features**: Split Hero Stage, Shift Management, Campaign Knowledge Base, Volunteer Media Gallery

## Live Preview
Run locally using Python's built-in web server:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000/index.html` or `http://localhost:8000/portal.html`.
